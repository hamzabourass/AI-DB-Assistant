# Schéma de Base de Données pour les Commandes Clients Oracle apex

## Description
Cette documentation fournit un aperçu détaillé de la structure de la base de données, y compris les tables, colonnes, types de données, contraintes et relations.

## 2. Tables et Relations

### CUSTOMERS (Clients)
- **CUSTOMER_ID** : Identifiant unique du client (*NUMBER*, non nullable, Clé Primaire).
- **EMAIL_ADDRESS** : Adresse e-mail du client (*VARCHAR2(255)*, Unique, non nullable).
- **FULL_NAME** : Nom complet du client (*VARCHAR2(255)*, non nullable).

### ORDERS (Commandes)
- **ORDER_ID** : Identifiant unique de la commande (*NUMBER*, Clé Primaire, non nullable).
- **CUSTOMER_ID** : Référence vers CUSTOMERS (*NUMBER*, Clé étrangère, non nullable).
- **ORDER_DATETIME** : Date et heure de la commande (*TIMESTAMP(6)*, non nullable).
- **ORDER_STATUS** : Statut de la commande (*VARCHAR2(10)*, non nullable).
- **STORE_ID** : Référence vers STORES (*NUMBER*, Clé étrangère, non nullable).

### ORDER_ITEMS (Détails de Commande)
- **ORDER_ID** : Référence vers ORDERS (*NUMBER*, Clé étrangère, non nullable).
- **LINE_ITEM_ID** : Identifiant de l'article dans la commande (*NUMBER*, Clé Primaire, non nullable).
- **PRODUCT_ID** : Référence vers PRODUCTS (*NUMBER*, Clé étrangère, non nullable).
- **QUANTITY** : Quantité commandée (*NUMBER*, non nullable).
- **UNIT_PRICE** : Prix unitaire (*NUMBER(22,2)*, non nullable).

### PRODUCTS (Produits)
- **PRODUCT_ID** : Identifiant unique du produit (*NUMBER*, Clé Primaire, non nullable).
- **PRODUCT_NAME** : Nom du produit (*VARCHAR2(255)*, non nullable).
- **UNIT_PRICE** : Prix unitaire (*NUMBER(22,2)*, nullable).
- **PRODUCT_DETAILS** : Détails du produit (*BLOB*, nullable).

### STORES (Magasins)
- **STORE_ID** : Identifiant unique du magasin (*NUMBER*, Clé Primaire, non nullable).
- **STORE_NAME** : Nom du magasin (*VARCHAR2(255)*, Unique, non nullable).
- **PHYSICAL_ADDRESS** : Adresse physique (*VARCHAR2(512)*, nullable).

---
## 3. Relations Entre les Tables
- **CUSTOMERS** (1) ➝ (N) **ORDERS** via `CUSTOMER_ID`
- **ORDERS** (1) ➝ (N) **ORDER_ITEMS** via `ORDER_ID`
- **ORDER_ITEMS** (N) ➝ (1) **PRODUCTS** via `PRODUCT_ID`
- **ORDERS** (N) ➝ (1) **STORES** via `STORE_ID`

---
## 4. Requêtes SQL Utiles

### Lister toutes les commandes avec les noms des clients
```sql
SELECT o.ORDER_ID, c.FULL_NAME, o.ORDER_DATETIME, o.ORDER_STATUS 
FROM ORDERS o 
JOIN CUSTOMERS c ON o.CUSTOMER_ID = c.CUSTOMER_ID;
```

### Trouver les produits commandés par un client donné
```sql
SELECT p.PRODUCT_NAME, oi.QUANTITY, oi.UNIT_PRICE 
FROM ORDER_ITEMS oi
JOIN PRODUCTS p ON oi.PRODUCT_ID = p.PRODUCT_ID
JOIN ORDERS o ON oi.ORDER_ID = o.ORDER_ID
WHERE o.CUSTOMER_ID = 1;
```

### Nombre total de commandes par magasin
```sql
SELECT s.STORE_NAME, COUNT(o.ORDER_ID) AS TOTAL_COMMANDES
FROM ORDERS o
JOIN STORES s ON o.STORE_ID = s.STORE_ID
GROUP BY s.STORE_NAME;
```
