Oracle SQL Syntax Rules and Guidelines:

1. **General Rules**:
   - Oracle SQL is case-insensitive for keywords (e.g., `SELECT`, `FROM`, `INSERT`), but it is case-sensitive for object names (e.g., table names, column names) if they are created with double quotes.
   - Always terminate SQL statements with a semicolon (`;`).

2. **Creating Sequences**:
   - Use the `CREATE SEQUENCE` statement to create a sequence.
   - Example:
     ```sql
     CREATE SEQUENCE EMPLOYEE_SEQ
     START WITH 1
     INCREMENT BY 1
     NOCACHE
     NOCYCLE;
     ```

3. **Creating Tables**:
   - Use the `CREATE TABLE` statement to create a table.
   - Specify column names, data types, and constraints (e.g., `PRIMARY KEY`, `NOT NULL`, `UNIQUE`).
   - Example:
     ```sql
     CREATE TABLE EMPLOYEES (
         EMPLOYEE_ID NUMBER PRIMARY KEY,
         FIRST_NAME VARCHAR2(50) NOT NULL,
         LAST_NAME VARCHAR2(50) NOT NULL,
         EMAIL VARCHAR2(100) UNIQUE NOT NULL,
         HIRE_DATE DATE NOT NULL,
         SALARY NUMBER(10, 2),
         DEPARTMENT_ID NUMBER,
         CONSTRAINT FK_DEPARTMENT FOREIGN KEY (DEPARTMENT_ID) REFERENCES DEPARTMENTS(DEPARTMENT_ID)
     );
     ```

4. **Inserting Data**:
   - Use the `INSERT INTO` statement to insert data into a table.
   - Oracle does not support inserting multiple rows in a single `INSERT` statement. Use separate `INSERT` statements for each row.
   - Example:
     ```sql
     INSERT INTO EMPLOYEES (EMPLOYEE_ID, FIRST_NAME, LAST_NAME, EMAIL, HIRE_DATE, SALARY, DEPARTMENT_ID)
     VALUES (EMPLOYEE_SEQ.NEXTVAL, 'John', 'Doe', 'john.doe@example.com', DATE '2023-01-15', 50000, 10);

     INSERT INTO EMPLOYEES (EMPLOYEE_ID, FIRST_NAME, LAST_NAME, EMAIL, HIRE_DATE, SALARY, DEPARTMENT_ID)
     VALUES (EMPLOYEE_SEQ.NEXTVAL, 'Jane', 'Smith', 'jane.smith@example.com', DATE '2023-02-20', 60000, 20);
     ```

5. **Date Format**:
   - Use the `DATE` keyword followed by a string in the format `'YYYY-MM-DD'` to insert date values.
   - Example:
     ```sql
     INSERT INTO EMPLOYEES (EMPLOYEE_ID, FIRST_NAME, LAST_NAME, EMAIL, HIRE_DATE, SALARY, DEPARTMENT_ID)
     VALUES (EMPLOYEE_SEQ.NEXTVAL, 'Alice', 'Johnson', 'alice.johnson@example.com', DATE '2023-03-25', 55000, 10);
     ```
